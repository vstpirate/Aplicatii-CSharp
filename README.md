# Aplicatii-CSharp

Colectie de aplicatii consola in C#, realizate la disciplina Planificarea aplicatiilor desktop.

## Tehnologii
- C# / .NET 10
- Visual Studio 2025
- Git si GitHub

## Proiecte

### 1. DreptunghiApp
Calculeaza aria si perimetrul unui dreptunghi. Verifica daca valorile sunt pozitive.

```
Lungime: 12
Latime: 4
Aria = 48
Perimetrul = 32
```

### 2. CatalogNote
Calculeaza media a 6 note si afiseaza daca studentul a promovat.

```
Note: 8, 9, 10, 7, 6, 9
Media: 8.17
Promovat
```

### 3. ProduseApp
Afiseaza o lista de produse si calculeaza totalul.

```
Caiet: 15 lei
Pix: 8 lei
Radiera: 5 lei
Total: 28 lei
```

### 4. MeniuAplicatie
Prototip de meniu pentru o aplicatie desktop, cu optiunea 4. Iesire.

```
APLICATIE GESTIUNE
1. Clienti
2. Programari
3. Rapoarte
4. Iesire
Alegeti optiunea: 2
Modul Programari
```

## Rulare
1. Deschideti fisierul .csproj al proiectului in Visual Studio.
2. Apasati Ctrl+F5.
